# Release manifest — v1.0.0

This public repository was assembled from selected authored C++ source in a new,
clean Git history. The original thesis and demo repositories were not pushed.

Included: C++ pipeline, core test, sanitized verification summaries, synthetic
CSV smoke sample, documentation, and configuration. Excluded: model weights,
ONNX graph, dataset images, third-party source/binaries, original experiment
logs, private paths, complete thesis, and internal audit files.

The MIT license covers the authored source and documentation in this repository
only. OpenCV, ONNX Runtime, separately obtained models, and datasets remain
under their own terms and are not relicensed here.
