# Scope and limitations

- Reference implementation only; no production factory or semiconductor fab deployment.
- The public sample is self-generated and has no industrial performance meaning.
- Model weights and dataset images are excluded; model-backed parity cannot be rerun from this repo alone.
- The saved EfficientAD-S model and frozen threshold are research artifacts, not validated release limits.
- Local CPU latency does not represent factory line rate or hardware integration.
- Heatmap color is illustrative, not calibrated defect probability.
- The research asks about deployment reliability; it does not propose a new anomaly detector.
- External findings and theoretical statements apply only within their documented evidence boundaries.
